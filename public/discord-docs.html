The Discord Bot workspace is intentionally separate from the Minecraft account tools. When enabled, it will use Discord OAuth2 for server selection and bot management.

COMMAND STRUCTURE
/setupInitial server setup and dashboard configuration.
/helpDisplays available commands and categories.
/configOpens configurable bot features for authorized staff.
/panelCreates or opens the persistent control panel.
DASHBOARD

The planned dashboard will authenticate through Discord OAuth2, display the guilds the user can manage, and expose bot settings only for authorized servers.
